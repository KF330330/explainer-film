# 场景代码写法（WB 白板库）

> 何时读：派 Opus 子代理写 `engine/<film>/scenes/*.js` 之前（它要读这份）；主会话改场景、查死帧时也读。API 签名以 `vendor/docs/接口速查.md` 与 `engine/<film>/wb/common.js` 源码为准。

## 骨架

```js
// B3 · 一段注释写清这一段板上有什么、相机去哪、哪句触发什么
WB.chapter('B3', id => {
  const { OR, INK, SOFT, DIM, BODY, NUMF, FONT, CARD } = WB, L = WB.L, qb = WB.qb;
  // …往 WB.S 排笔画、往 WB.K 排相机键…
});
SCENES['B3'] = WB.scene;
```

- 整片一块板、一台相机：每段文件只是把笔画与相机键排进时间线，`WB.scene` 对所有段相同；`B0.js` 顶部定全片版式 `WB.L`（各块的世界坐标框），别的段只引用。
- 第 0 帧不能空：片头板上先有一样东西正在画（对象先出）。

## 对位：念到才起笔

```js
const t0 = Math.max(qb('B3_05', '7 轮') + 0.15, prev.t1 + 0.04);   // 念到那个词 +0.05~0.2 s，且不抢上一笔
const s = WB.text('7 轮 4 天', x, y, 44, { t0, rate: 8, fam: BODY, el: 'card1.l3' });
WB.ev('B3_05', 'card1.l3', 'write', s);                               // 登记给 QA（el/do 与 timeline 一致）
```

- `qb(节拍, '词')`：该词在该节拍口播里开始念的全片秒（词须在该拍 `say` 里恰好出现一次）；`WB.qbe` 取念完时刻；`WB.vo(拍)` 取 `[句首, 句尾]`；`TMB.ev(拍, el, do)` 读 timeline 里的事件参数。
- 几乎每一笔都显式给 `t0`，不靠 `WB.cur` 流水；一句口播里至少一样「说到的东西」在动，**口播期间任何连续 1.5 s 内都要有笔在动**（pen_idle 门禁）。
- 元素入场比该词开口晚 0.2–0.5 s；入场 0.3–0.4 s、退场 ≈0.18 s；同一时刻只一个主角入场。

## 数字落定（cnt 模板）

```js
const cnt = (beat, el, x, y, o = {}) => {
  const e = TMB.ev(beat, el, 'count'), land = TMB.landOf(e);                  // 落定＝land_cue 末尾＋offset
  const t0 = Math.min(land - 0.6, Math.max(land - 1.3, qb(beat, e.at)));      // 念到那个数起跳，滚 0.6–1.3 s
  const n = WB.count(x, y, { from: e.from, to: e.to, fmt: e.fmt, land, dur: land - t0, slamIn: true, el, ...o });
  WB.ev(beat, el, 'count', n, land - t0); return n;
};
```

- 落定后数字停 ≥0.5 s；用等宽数字（`TY.tabular`）防抖。
- **终值只在落定那一帧出现**：缓动（expoOut）会让显示值提前几百毫秒就到终值。写 `fmt` 的显示函数时，`p < 1` 期间把值钳在「终值减最小步长」以下，`p ≥ 1` 才显示终值（不这么做的话，终值会比口播早出现 0.17–0.87 s）。
- 箭头、标签和数字同时写，不先画箭头干等。
- 要里程表式的滚动（数位一格一格滚上去、落定前各位对齐）就用 `WB.roll`，模板 rcnt 见 `parts.md` 第十三节；别用早期样片那种 `L.count` 写法（滚到一半数位硬切成半截）。

## 相机：只在该看新东西时动，停稳再落笔

```js
WB.shotRect(t, 0.9, L.cardBB(0), { zmax: 1.3 });   // 框住卡① 的世界框，0.9 s 到位
// 之后的笔画从 t + 0.9 + WB.SETTLE 起笔；build 会把落在运镜里的起笔自动顺延 ≤0.35 s，但别依赖它
WB.ev('B3_08', 'cam', 'camera', t, 0.9);           // 运镜也登记
```

- 缓推 0.6–1.5 s（推 10–40%）、横移 0.5–0.9 s、拉远 0.8–2 s；快推 ≤1/3 镜头、≤8 次/分钟、不连三镜往里推；停留时 `creep 0`。
- 换行用 `WB.lead(a, b, t0, dur)` 引线＋甩镜，之后 `WB.fade(WB.S.slice(n0), t, .4)` 擦掉引线。
- 长距离用 `WB.travel`（先拉远再推近）；收尾 `shotRect(L.all, { zmax: .3 })` 拉远看全板并静持 1.2 s（全片唯一允许的冻结）。**拉远要在末句口播里做完**：相机最晚在末 cue 结束 +0.2 s 前停稳，之后到片尾一笔不动——qa 的 `still_video` 用「末 cue 结束 +0.2 s → 片尾」这段的噪声标定阈值 K，这段里相机或任何件在动，K 会被抬到全片都判静止（FAIL）。末句太短放不下「最后一笔 → 拉远」时，拉远可以和末句最后一个动作首尾相接（动作起笔早于起镜，不在运镜里起笔）。
- 字幕带（底部 200 px）是内容禁区：`WB.fit` 取景上下界 70–870；四边安全区 110 px；1080p 下正文 ≥32 px、标签 ≥40、标题 ≥80。

## 常用件

`WB.line / text(rate, fam, wt, rot) / pop(at, slam) / ring / under / strike / arrow / grow(按 phases 分段长) / card / pill / stamp / count / dimEl / fade / group(el, fn)`；小图标 `tick / cross / page / stackIcon / magnifier / wavy / lockIcon / eyeOff / clockIcon / ticket`；多笔草图 `sketch`。曲线线头跟口播走用 `WB.custom`＋`DG.drawPartial`。

## 像 PPT 的根子（审片会抓）

每镜同一个动作；全员呼吸、字漂浮、匀速慢推这类装饰性假动；三张卡像 bullet（画成两叠纸＋章、箭头流、两根短柱）；拐点堆红；贴边裁半；无内容推拉；笔比相机先动；一镜多个东西同时入场。

## 穿帮的根子（画面轮换版审片抓到的）

1. **上屏字不早于口播**：图上的标签与数字（「每年 7%」「×2」）念到才出现，不提前闪现。
2. **出现后不许很快被盖住**：刚写出的字要停到观众读完，下一张卡不立刻盖上去；会被盖的字改写在之后还看得到的地方。
3. **结论画完停够再运镜**：结论句写完先停够再拉远，不能只露 0.1 s 就被运镜带走。
4. **落地画面须已有主体**：相机落地前画面里已有东西（`docCard` 的 `base` 先摆空卡底，或预摆件），不停在空纸上等东西擦入；上一画面的残留（引线、箭头尾巴）切走前撤掉。
5. **全片结论带进收尾**：收尾拉远时，全片结论（如两条秘诀）还在画面里。
6. **同一个量两种画法比例一致**：同一个倍数在坐标图与实物里比例相同（硬币摞 ×45 是 ×15 的 3 倍高，坐标图纵轴就用线性，不让它只有 1.9 倍）。
7. **画面会引出的错误算术要堵**：画面一摆就可能让人算错的，旁边补一行小字写清（「差 30 倍」旁写「45 − 15 = 30」，免得拿 45 ÷ 15 算成 3 倍）。
8. **颜色跟着意思走**：一张图里一种颜色只指一样东西（7% 线的「×2」不借 10% 线的红色）。
9. **原件要是内容本身**：上台的原件只能是口播说到的那件事的真迹，或我们做法的真实产物（长版说法见 `templates/脚本与分镜.md` 第 5 行）；谐音、同名、装饰性古画古书不算，没有就写「无原件：原因」。反例：一支讲「出考卷」的样片借「考卷」谐音放了明代会试录古籍图，与内容无关、反增误导，后来撤了。

## 挪开配角（擦上一格）先按页核三点

推到下一格时把上一格的配角擦掉（只留格标题与结论词），擦之前按页逐条核：

1. **擦的过程会不会被镜头拍到**：拍得到就不擦，或者等它出了画再用 `WB.retire` 撤掉。
2. **擦完剩下的是一句能自己讲清的结论，还是孤词、空标题**：剩孤词就不擦。
3. **这页之后会不会拉回整页、停 ≥3 s**：会就不擦（整页停在残页上，观众看到的是一页被擦空的板）。

三点都过才擦。审片尺子 ⑬ 查这一条（`review-and-delivery.md`）。

## 换页方式要轮换

换页有三式：A 引线（`WB.lead`＋`WB.trip`／`WB.travel`）、B 平移（`WB.panTo`）、C 拉远回顾（`WB.review`），签名、用法与共用的时刻规矩见 `parts.md` 第十四节。

- 同一式最多连用 2 次；全片换页 ≥5 次时至少用两式。
- 一支 11 次换页全用引线的片子，观众说「看多了腻」；改成引线 3、平移 5、拉远回顾 3 后才顺。审片尺子 ⑬ 查这一条。
